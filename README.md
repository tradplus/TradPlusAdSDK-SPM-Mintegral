# TradPlus Mintegral Adapter Swift Package

Swift Package Manager support for the TradPlus Mintegral adapter (15.14.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Mintegral.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Mintegral.git", exact: "15.14.0")
```

Third-party dependency: Mintegral SDK `8.1.5`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.14.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
